about=Classifies railway corridor LiDAR point clouds (LAS / LAZ / COPC)
    with a deep-learning model at 5 cm, using XYZ only. Seven classes:
    ground (track bed and platforms), rail, pole (catenary masts,
    portals and supports), wire, vegetation, fence and other. Every
    output code is editable; the defaults follow the ASPRS LAS 1.4
    table where a class exists. The model weights ship with the plugin.
    A one-click setup installs PyTorch and the LiDAR packages into a
    separate per-user folder on first use (no admin rights). Files in
    feet are converted from their CRS; tiling and streaming handle
    files larger than RAM. Requires an NVIDIA GPU with a current driver.
