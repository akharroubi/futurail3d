# Changelog

## 1.0.0 (2026-11-05)

- First delivery of Rail 3D: the railway classifier (ground, rail, pole,
  wire, vegetation, fence, other) with editable output codes, the one-click
  setup of the Python environment, automatic tiling and streaming of large
  files, unit conversion from the file's CRS, a Processing algorithm
  (`rail3d:classify_point_cloud`) and 2D / 3D styling of the results.
